# Contact Book

A simple Python-based Contact Book application that allows users to manage contacts through a command-line interface.

## Features

* Add new contacts
* View saved contacts
* Search for contacts
* Update contact information
* Delete contacts
* Simple menu-based interface

## Technologies Used

* Python 3
* Python built-in data structures and functions

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Mona-rajpoot/Contact-Book.git
```

### 2. Navigate to the project directory

```bash
cd Contact-Book
```

### 3. Run the program

```bash
python contact_book.py
```

## How It Works

The application provides a menu that allows the user to perform different operations on contacts.

1. Select an option from the menu.
2. Enter the required contact information.
3. The program performs the selected operation.
4. Continue using the menu until the user chooses to exit.
